# ArcSprout Economic Loop v1

## Product Thesis

ArcSprout is an AI-gated onchain growth system on Arc.

The first job of the product is not to mint an NFT. The first job is to turn real onchain participation into identity, access, and long-term utility.

In simple terms:

- `Score` decides whether a wallet has earned entry.
- `APT` powers the ecosystem economy.
- `ArcSprout NFT` represents identity, evolution, and privileges.

The system should feel alive:

`activity -> score -> mint -> evolution -> privilege -> more activity`

## Core Principles

1. `Utility first`
   Every mechanic must create real usage, not empty speculation.

2. `Meaningful activity over spam`
   Grinding should reward useful participation, not cheap transaction loops.

3. `NFT as living identity`
   The NFT should evolve with behavior and contribution, not stay static after mint.

4. `APT as economic fuel`
   APT should be used across actions, rewards, and ecosystem services.

5. `Privileges must be earned and capped`
   Higher levels can unlock stronger benefits, but reward design must stay sustainable.

6. `AI stays functional`
   AI is not cosmetic. It should evaluate, guide, and personalize progression.

## System Overview

### 1. Eligibility Engine

This layer decides whether a wallet is ready to mint.

Signals can include:

- Arc transaction count
- wallet age and retention over time
- staking activity
- swap activity
- bridge activity
- APT usage
- USDC usage
- use of future ArcSprout AI products

The key rule is that score must reward varied and repeated behavior, not one-dimensional spam.

Good examples:

- bridging to Arc and staying active for days
- staking APT and keeping a position open
- swapping through approved ecosystem rails
- paying for AI services with APT or USDC

Bad examples:

- sending the same tiny transfer back and forth
- burst activity in one hour with no retention
- wash-like loops that exist only to farm score

### 2. Economic Engine

This layer creates the wheel that keeps the system alive before and after mint.

APT should have real jobs:

- staking token
- swap token
- bridge-related utility token
- payment token for AI products or services
- quest reward token
- score boost token for approved actions

USDC can stay important as the stable-value rail for:

- AI service payments
- paired liquidity
- treasury accounting
- fee collection references

The economic idea is simple:

- user activity generates fees or protocol value
- some of that value supports the ecosystem
- some can flow back into qualified NFT holder privileges

### 3. Evolution Engine

This layer turns the NFT into a living membership object.

Suggested base path:

- `Seed`
  First successful mint. Proof of entry.

- `Sprout`
  Earned through repeated Arc activity and early APT usage.

- `Bloom`
  Earned through meaningful ecosystem participation, retention, and contribution.

- `Canopy`
  Earned through sustained value creation, liquidity support, AI commerce usage, or community leadership.

Evolution should not depend on balance alone. It should depend on a mix of:

- activity
- time
- contribution
- economic participation
- trust

### 4. Reward Engine

This layer defines what holders get.

Possible reward classes:

- access to gated products or channels
- better AI features
- quest priority
- partner perks
- fee distribution rights within a capped model
- governance weight for specific community decisions

Fee distribution should be treated as a protocol privilege, not a loose promise.

Suggested safeguards:

- only active holders can claim
- each level has a capped share range
- treasury keeps a reserve before distributions
- distribution only applies to approved fee sources
- anti-sybil and anti-spam checks remain active after mint

## User Loop

### Before mint

1. User connects wallet.
2. ArcSprout evaluates score.
3. If score is too low, the user is shown real paths to improve:
   - stake APT
   - swap on Arc
   - bridge assets
   - use AI services
   - keep returning over time

### Entry

1. User becomes eligible.
2. User mints the base ArcSprout NFT.
3. NFT starts at `Seed`.

### After mint

1. User continues onchain participation.
2. NFT evolves based on sustained behavior.
3. Higher levels unlock stronger privileges.
4. Privileges motivate more ecosystem use.

## APT Token Role

APT should not exist only as a ticker.

It should be useful across multiple loops:

- `Access`
  Some features can require APT usage.

- `Activity`
  Staking, swap, and payments can count toward progression.

- `Commerce`
  Future AI tools or products can be bought with APT.

- `Rewards`
  Quests or campaigns can pay in APT.

- `Alignment`
  Users who help the ecosystem grow have a stronger reason to stay.

## What Gives the NFT Value

The NFT should gain value from five things:

1. `Access`
   Holders can reach things non-holders cannot.

2. `Progression`
   The NFT can evolve, which gives users a reason to stay active.

3. `Economic privilege`
   Qualified holders can access a capped share of ecosystem fee flows.

4. `Identity`
   The NFT proves history, level, and trust.

5. `Usefulness`
   The NFT keeps mattering after mint because the ecosystem keeps moving.

## What Must Be Avoided

- reward models that only encourage fake volume
- score systems that can be gamed by tiny repeated transfers
- giving every holder identical benefits forever
- promising uncapped passive yield
- using AI only as branding instead of real system logic

## Recommended Rollout

### Phase A

Ship the clean foundation:

- wallet evaluation
- clear score improvement paths
- base NFT mint
- Seed level

### Phase B

Add the first real economy loops:

- APT staking
- swap integration references
- bridge activity recognition
- simple evolution logic from Seed to Sprout

### Phase C

Add post-mint retention:

- quests
- AI guidance
- fee-backed privileges with caps
- Bloom and Canopy levels

### Phase D

Expand the ecosystem:

- AI commerce
- partner products
- governance and reputation modules

## Short Version

ArcSprout should become:

`an AI-powered Arc membership system where onchain activity earns identity, identity evolves into privileges, and privileges drive a self-sustaining ecosystem loop`
